# SpamShield – Email Spam Classifier

## Project Overview

SpamShield is a web-based Email Spam Detection System developed using Django and MongoDB. It allows users to register, log in, and detect whether an email is Spam or Safe using Regex Pattern Analysis and predefined spam keywords. Users can also upload text files for batch email detection, view detection history, check statistics, and access the REST API.

## Features

- User Registration
- User Login & Logout
- Email Spam Detection
- Regex Pattern Analysis
- URL Detection
- ALL CAPS Detection
- Batch Email File Upload (.txt)
- Detection History
- Delete History
- Statistics Dashboard (Total, Spam, Safe)
- User Profile
- REST API (DRF)

## How I Run the Project 
### Step 1 
I created the SpamShield project in Visual Studio Code. 
### Step 2 
I created and activated the virtual environment. 
### Step 3
I installed Django, PyMongo, and Django REST Framework. 
### Step 4 
I started the MongoDB server. 
### Step 5 
I created the spamshield database with users and history collections. 
### Step 6 
I developed the project features such as registration, login, spam detection, batch upload, history, statistics, and API. 
### Step 7 
I configured all URL routes. 
### Step 8 
I ran the project using: python manage.py runserver 
### Step 9 
I opened the application in the browser: http://127.0.0.1:8000/ 
### Step 10
I registered a user, logged in, and tested all project features.
